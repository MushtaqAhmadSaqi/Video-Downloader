MultiVid

MultiVid is a free starter project for downloading video info and media using Flask + yt-dlp on your own machine.

What you get

  • Simple modern UI
  • Video title, thumbnail, uploader, and duration
  • Available format list
  • Video and MP3 download support
  • GitHub Pages docs support

Free resources

  • Flask docs
  • yt-dlp install guide
  • FFmpeg downloads
  • GitHub Pages docs
